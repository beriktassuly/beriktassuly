## chatpack

I build [chatpack](https://chatpack.berektassuly.com/), a Rust library for converting chat exports into compact, LLM-ready data. The project has regular users and includes a CLI, Python bindings, and a browser app powered by WebAssembly.

[Source code](https://github.com/beriktassuly/chatpack) · [Rust crate](https://crates.io/crates/chatpack)
